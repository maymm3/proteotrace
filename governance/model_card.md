# Model card: ProteoTrace reporting agent, planned component

## Intended use

To summarise results generated by validated ProteoTrace tools for trained researchers.

## Out of scope

Diagnosis, prognosis, treatment recommendation, autonomous clinical decision-making, and use with unapproved sensitive data.

## Safety design

The agent will have access only to pre-approved analysis tools and exported result files. It must cite output filenames, identify uncertainty, and state that expert review is required.

## Evaluation before release

The agent will be tested for numerical faithfulness, citation faithfulness, refusal of clinical-decision requests, and correct disclosure of data limitations.
